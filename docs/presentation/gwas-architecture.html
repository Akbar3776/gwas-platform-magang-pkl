Arsitektur Sistem

Topologi Sistem 3-Tier End-to-End

Pemisahan tugas yang tegas antara visualisasi antarmuka pengguna, gateway API terpusat, dan worker komputasi genomik terdistribusi.

Tier 1: Klien & Visualisasi

Frontend Web (React 18 + Vite)

Single Page Application responsif yang mengutamakan interaktivitas data analitik genetik tanpa hambatan performa.

  • Rendering Manhattan Plot via HTML5 HiDPI Canvas ($10^6$ varian SNP).
  • Interaktivitas Plotly WebGL untuk QQ Plot, Scree Plot, & Matriks Kinship Heatmap.
  • State session terpusat dengan AuthContext, axios interceptor, dan token JWT.
  • Manajemen upload file besar melalui algoritma chunked upload 5MB berulang.
Tier 2: Layanan API

Backend Gateway (FastAPI)

REST API berkinerja tinggi berbasis ASGI Python dengan validasi skema DTO yang ketat sebelum komputasi dimulai.

  • Endpoints modular: /auth, /upload, /jobs, /results, dan /capabilities.
  • Validasi parameter input otomatis menggunakan model Pydantic v2.
  • SQLAlchemy 2.0 ORM dengan pooling koneksi untuk persistensi metadata.
  • Pemeriksaan kepatuhan file fenotipe dan validasi multialelik VCF sebelum antrean.
Tier 3: Mesin Komputasi

Worker Asinkron (Celery + Redis)

Klaster worker komputasi independen yang mengeksekusi 10 tahapan pipeline analisis genomik secara aman dan terisolasi.

  • Antrean tugas background decoupling via broker Redis in-memory.
  • Orkestrasi wrapper biner CLI native: PLINK2, GEMMA Wald, Beagle 5.4, BCFtools.
  • Tracking progres real-time per tahap dengan persistence atomic ke database.
  • Sandbox penyimpanan data per dataset di direktori storage terenkripsi.

Kontrak Data

Skema Validasi Pydantic v2

Memastikan integritas seluruh request DTO sebelum diteruskan ke mesin bioinformatika:

  • FullPipelineRequest: Validasi batas MAF [0.01 - 0.5], GENO [0 - 0.2], MIND [0 - 0.2].
  • Aturan Organisme: Penegakan nonaktifnya filter HWE otomatis untuk tanaman inbred lines.
  • Imputation Mode: Pilihan mode reference-free vs reference-guided dengan validasi path.
  • Model Asosiasi: Seleksi otomatis LMM vs GLM berdasarkan struktur kovariat populasi.

Keamanan & Autentikasi

Proteksi data riset sensitif dan kepatuhan privasi data genomik:

  • Stateless JWT Bearer Token dengan algoritma enkripsi HS256 / RS256.
  • Password hashing menggunakan Bcrypt dengan cost factor adaptif.
  • Isolasi direktori storage fisik per user UUID di backend/data/storage.
  • CORS Middleware terproteksi dengan header whitelist domain terkontrol.

Bioinformatics Pipeline

Alur Komputasi GWAS (Tahap 1 – 4)

Fase pra-analisis: rekonsiliasi sampel, normalisasi varian, pengendalian kualitas (QC), dan imputasi genotipe.

Tahap 1

Inspeksi & Rekonsiliasi

Pencocokan akurat antara ID sampel pada VCF dan fenotipe.

  • Validasi kolom IID (Individual ID).
  • Deteksi sampel hilang pada salah satu sumber data.
  • Inspeksi distribusi nilai trait (kontinu vs biner).
Tahap 2

Normalisasi VCF

Standardisasi varian via BCFtools pipeline.

  • Sorting koordinat posisi kromosom.
  • Pemecahan multialelik jadi bi-alelik.
  • Pengindeksan file .tbi/.csi untuk akses acak cepat.
Tahap 3

Quality Control (QC)

Penyaringan varian berkualitas rendah via PLINK2.

  • Filter MAF < 0.05 untuk varian langka.
  • Filter missingness varian & sampel (GENO & MIND > 5%).
  • Filter HWE outcross (bypass untuk inbred lines).
Tahap 4

Imputasi Genotipe

Inferensi genotipe hilang via Beagle 5.4.

  • Model Hidden Markov Model berbasis fase LD.
  • Mode Reference-Guided atau Reference-Free.
  • Bypass otomatis jika call rate sudah optimal.

Bioinformatics Pipeline

Alur Komputasi GWAS (Tahap 5 – 7)

Analisis struktur stratifikasi populasi, pengujian asosiasi genetik statistik, dan model multi-lokus.

Tahap 5

Struktur Populasi & LD

Mengoreksi perancu (confounding) genetik sebelum uji statistik asosiasi.

  • LD Pruning: Menyaring varian berkorelasi tinggi (window 50kb, step 5, r² 0.2).
  • Principal Component Analysis (PCA): Menghitung 10 PC untuk menangkap sub-populasi.
  • Matriks Kinship vanRaden: Menghitung hubungan kekerabatan sampel genotipe.
  • Kurva LD Decay: Menilai laju penurunan korelasi LD per rentang jarak fisik (kb).
Tahap 6

Analisis Asosiasi GWAS

Pengujian korelasi statistik antara varian genetik dan fenotipe target.

  • Linear Mixed Model (LMM via GEMMA): Model paling akurat yang mengontrol struktur populasi (Fixed Effect: PC1-PC3, Random Effect: Kinship).
  • Generalized Linear Model (GLM via PLINK2): Alternatif berkecepatan tinggi dengan kovariat PC.
  • Mode Rekomendasi Otomatis (AUTO): Sistem mengevaluasi Lambda GC dan Kinship untuk memilih model terbaik.
Tahap 7

Multi-Locus GWAS

Pendekatan iteratif multi-lokus untuk mendeteksi varian dengan efek minor.

  • FarmCPU (Fixed and random model Circulating Probability Unification).
  • BLINK (Bayesian-information and Linkage-disequilibrium Iteratively Nested Keyway).
  • Mengatasi kelemahan Single-Marker Analysis dengan mengontrol pseudo-QTN sebagai kovariat.
  • Integrasi modular melalui wrapper script R/GAPIT jika lingkungan komputasi mendukung.

Bioinformatics Pipeline

Alur Komputasi GWAS (Tahap 8 – 10)

Evaluasi ambang signifikansi, pengelompokan varian (clumping), visualisasi cache, dan anotasi fungsional GFF3.

Tahap 8

Pasca-GWAS & Clumping

Menentukan batas signifikansi dan mengidentifikasi lokus independen teratas.

  • Ambang Bonferroni: Alpha konservatif disesuaikan dengan jumlah varian ($0.05 / M$).
  • Benjamini-Hochberg FDR: Koreksi False Discovery Rate $q < 0.05$.
  • LOD Score: Ambang batas berbasis LOD (LOD $\ge 5.6$ setara $p < 2.51 \times 10^{-6}$).
  • LD Clumping: Mengelompokkan varian berkorelasi $r^2 \ge 0.2$ di sekitar Lead SNP utama.
Tahap 9

Visualisasi & Plot Caching

Mempersiapkan data plot siap saji berkecepatan tinggi untuk antarmuka web.

  • Kalkulasi koordinat Manhattan Plot ($-\log_{10} p$ terhadap posisi kromosom).
  • Binning & decimation data untuk mengurangi footprint payload transmisi jaringan.
  • Kalkulasi distribusi kuantil teramati vs teoretis untuk QQ plot.
  • Estimasi faktor inflasi genomik Lambda GC ($\lambda = 1.044$ membuktikan kontrol ideal).
Tahap 10

Anotasi Gen GFF3

Menghubungkan temuan statistik dengan biologi fungsional gen kandidat.

  • Pemetaan Lead SNP ke interval fitur genom referensi pada file GFF3.
  • Klasifikasi Genik vs Near-Gen berdasarkan jarak ke Transcription Start Site (TSS).
  • Ekstraksi ID gen, simbol gen, dan anotasi ontologi (Gene Ontology / GO terms).
  • Penyusunan tabel gen kandidat yang siap diunduh untuk publikasi riset.

Tooling & Engine

Integrasi Mesin Bioinformatika CLI

Wrapper eksekusi native berkinerja tinggi yang aman, terkontrol, dan terisolasi dari lingkungan sistem operasi.

Spesifikasi Mesin Native
PLINK 2.0 (v2.00a3LM) C++ Multi-threaded

Konversi VCF ke PGEN/BED, kalkulasi MAF, HWE, MIND, GENO, LD Pruning, PCA, dan GLM.

GEMMA (v0.98.5) C++ / GSL

Genome-wide Efficient Mixed Model Association: Mengestimasi varians dan Wald test dengan matriks Kinship.

Beagle 5.4 & BCFtools Java 17 & C

Imputasi genotipe berbasis populasi berkecepatan tinggi serta manipulasi streaming VCF indeks.

Protokol Eksekusi Aman

Pencegahan Injeksi & Error Handling

  • Array Arguments: Semua perintah CLI dilewatkan sebagai list token ['plink2', '--bfile', ...] tanpa shell interpolation (mencegah shell injection).
  • Execution Timeout: Batas waktu eksekusi maksimal pada subprocess untuk mencegah proses zombie atau hanging.
  • Return Code Inspection: Exit code non-zero memicu exception terstruktur dengan menyertakan isi stderr kesalahan.

Artefak Keluaran Terstruktur

Estimasi Skalabilitas Data Genomik Skala Besar

Dengan streaming I/O teroptimasi dan eksekusi multi-core PLINK/GEMMA, dataset $100.000$ SNP diproyeksikan selesai dalam 35–50 detik, dan dataset $10^6$ SNP (1 juta varian) selesai dalam 4–8 menit pada server 8-core standar.

Strategi Efisiensi Memori
  • Chunked Uploading: Memori server tidak terbebani file VCF ratusan megabyte karena data dikirim dalam chunk 5MB dan digabung streaming di disk.
  • Canvas Decimation: Manhattan Plot mereduksi titik bertumpuk pada region non-signifikan sehingga browser hanya merender varian yang informatif.
  • Storage Lifecycle Cleanup: Layanan background membersihkan file sementara secara berkala dan hanya menyimpan file output bernilai analitik tinggi.

Kesimpulan & Masa Depan

Kesimpulan Rekayasa & Roadmap Pengembangan

Pencapaian platform saat ini dan arah inovasi arsitektur komputasi genomik di masa mendatang.

Pencapaian Arsitektur Saat Ini
  • Pipeline 10 Tahap End-to-End: Mengintegrasikan seluruh siklus studi GWAS dari file mentah VCF hingga gen kandidat fungsional GFF3.
  • Pemisahan Tugas Bersih: FastAPI ASGI + Celery Distributed Workers + React 18 Canvas Visualizer.
  • Validasi Ketat: Perlindungan terhadap inkonsistensi data fenotipe dan otomatisasi pemilihan model statistik terbaik.
  • Transparansi Analitik: Seluruh 50 file log dan artefak per tahap dapat diunduh dan diverifikasi secara independen.
Rencana Pengembangan Kedepan (Roadmap)
  • Akselerasi GPU untuk LMM: Implementasi solver matriks berbasis PyTorch/CUDA untuk mempercepat analisis pada populasi > 20.000 sampel.
  • Integrasi IGV.js Tersemat: Genome browser interaktif langsung di dalam tab hasil untuk inspeksi pembacaan read alignment genetik.
  • Cloud-Native Kubernetes Deployment: Helm chart untuk deployment klaster otomatis dengan auto-scaling worker Celery berdasarkan beban antrean.
  • Export Laporan Standar Publikasi: Template generator otomatis naskah manuskrip jurnal ilmiah berformat LaTeX/DOCX.
